## Existing assertions and boundaries

- **H**: [household browser journey](../src/web/app/e2e/household-onboarding.e2e.ts), one case containing 14 steps against the running API, browser and disposable PostgreSQL. Selected positive assertions are identified below; none currently carries a native SB citation/result binding. The test also exercises real-time propagation, generated credentials and Chat access control.
- **B**: [development BFF browser journey](../src/web/app/e2e/development-bff.e2e.ts), one environment-selected case. It asserts cookie/session boundaries, Origin/CSRF rejection, logout revocation, expiry and two development identities. Keycloak is a development provider substitute. It does not establish invitation acceptance or live production OIDC interoperability.
- [Backend tests](../tests/backend/) provide complementary domain, application, controller and infrastructure evidence. Application fixtures generally use EF InMemory; controller tests do not constitute API E2E against a running application with PostgreSQL. The PostgreSQL event-log atomicity test is useful infrastructure evidence, not a substitute for all observable SB effects.
- Inbox unit assertions cover capture/events, isolated rejection and applied-result protection. Meal shopping-list handler tests inspect persisted event dispatch and repeated derivation; Recipe, Task, Routine, List and Area unit tests cover many local rules. Retain these assertions; add real application E2E for the full Given/When/Then and cross-module effects.
- The Chat journey stages a **Task** request and checks task counts; the accepted Chat SB requires a **Plan** proposal in Inbox. The private-thread access checks do not assert private action handling. Neither of the two Chat SBs is established by that journey.
- Existing temporary-password provisioning does not establish the accepted verified-identity invitation lifecycle. Keep [#281](https://github.com/juangcarmona/domusmind/issues/281) visible until implementation and actual acceptance evidence are confirmed.
