## Definition

A household note captured for later interpretation and review. An Inbox item retains its original text and owns the lifecycle of its proposals.

## Distinguish From

- **Inbox proposal**: a suggested action derived from the note; the note itself is not an action.

## Usage

Use Inbox item for the captured input and its status. Do not use it for a Plan, Task or conversation.
