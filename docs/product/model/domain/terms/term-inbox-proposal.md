## Definition

A structured action suggested from an Inbox item. A proposal has no effect on household state until a member approves it.

## Distinguish From

- **Plan** and **Task**: a proposal is not a household record. Only the owning area command can create one after approval.

## Usage

Use Inbox proposal for a single reviewable action. Do not call a proposal a Plan or Task before the owning area command succeeds.
