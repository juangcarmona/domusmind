## Definition

A household-scoped physical place with a name that members can reuse to locate managed Assets. An address is optional. A property Asset may be linked to a Location, but the place and the managed property are distinct concepts.

## Distinguish From

A Location describes where an Asset is. It is not the Asset itself, a containing parent Asset, legal ownership, an Area of responsibility or a Calendar place. Sharing a Location does not make two Assets part of one another.

## Usage

An authorized member may create a Location with a name and optional address, or select an existing one when organizing an Asset. A property can have its own Asset record, obligations and history while it and its equipment refer to the same Location. Location lifecycle beyond that minimum remains open.
