## Definition

Text contributed by a household member to a Chat thread. A message is retained as part of that thread's conversation history.

## Distinguish From

- An Inbox item is a separate capture record intended for interpretation and review.
- An assistant response is generated by DomusMind after explicit invocation and is distinguished from a member's message.

## Usage

Members read messages only in threads they are allowed to access. A message that invokes `@dm` may result in a separate assistant response in the same thread.
