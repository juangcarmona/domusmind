## Definition

A text response from DomusMind in a Chat thread, generated only after a member explicitly addresses `@dm`.

## Distinguish From

- A Chat message is written by a household member.
- An Inbox proposal is a reviewable suggestion for a household change; an assistant response is not a proposal or command.

## Usage

An assistant response answers from authorized DomusMind information, is stored in the thread as part of its history, and cannot itself change household state.
