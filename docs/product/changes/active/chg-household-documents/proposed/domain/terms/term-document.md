## Definition

A household-scoped record describing an important piece of paperwork and, when managed by DomusMind, its stored file version(s), access policy, lifecycle and contextual associations.

## Distinguish From

A Document is not the business entity it describes, a generic folder, or necessarily one immutable physical file. External URLs and metadata-only references are distinct from a file managed by DomusMind.

## Usage

Members search and retrieve a Document by useful metadata or context. A logical Document may have one or more file versions; a renewed policy may instead be a separate Document that supersedes an earlier one. Access is household- and document-policy-scoped.
