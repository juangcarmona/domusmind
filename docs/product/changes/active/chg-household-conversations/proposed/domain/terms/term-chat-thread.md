## Definition

A persistent household-scoped conversation shared by an explicit set of participants. A thread is either a private 1:1 conversation between two household members or a group conversation with managed membership. A thread may include the DomusMind assistant when it is explicitly started or addressed.

## Distinguish From

- An Inbox item is captured input for review, not a conversation history.
- A household timeline is a projection of dated household records, not a message thread.
- An external messaging channel or conversation is outside this term.

## Usage

Members use a thread to exchange messages, files and replies. They may explicitly invoke the assistant in a direct assistant thread or mention it in a group.
