## Definition

A response from the DomusMind assistant in a Chat thread, generated only after a member explicitly starts a direct assistant conversation or addresses the assistant in a group.

## Distinguish From

- A Chat message is written by a household member.
- An Inbox proposal is a reviewable suggestion for a household change; an assistant response is not itself a proposal or command.

## Usage

An assistant response is visibly attributed to DomusMind, identifies the provider route outcome required by the accepted assistant rules, is stored in the thread history and cannot itself change household state.
