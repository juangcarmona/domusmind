# DomusMind commit build

This bundle is generated by Aspire for the exact DomusMind image shown in the
release. It is a prerelease for a fresh self-hosted installation using the local
Ollama model. It does not deploy to a server.

1. Copy `.env.example` to `.env` and set `DB_USER`, `DB_PASSWORD`, and
   `JWT_SECRET` (at least 32 random characters).
2. Run `docker compose --file docker-compose.yaml config` to inspect the result.
3. Run `docker compose --file docker-compose.yaml up -d` on your own host.

The stack persists PostgreSQL, Ollama models, and ASP.NET Core Data Protection
keys in named volumes. Back up the database and key volumes before upgrading.
The app serves HTTP on port 24365; put your own TLS reverse proxy in front of it
if it is externally accessible.

Existing installations, and installations using the external interpreter,
Outlook integration, custom proxy settings, or a custom port, should continue
using the stable release's `deploy/docker-compose.yml` while those options are
ported to the Aspire distribution model.
